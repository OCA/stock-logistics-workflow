Use Cases / Context
===================

Fresh food and other variable-weight products are picked and packed by
hand. Operators record what they really prepared as a package count per
lot (for example, 2 packages of lot A, 4 of lot B and 5 of lot C), while
the moved weight rarely matches the ordered quantity.

In multi-step deliveries the picked quantity is propagated to the
delivery order. If the package count is recalculated from the new
weight, the operator's information is lost and misleading figures reach
the delivery (3.3 kg / 3 kg = 1.1 packages).

Preserving the original count lets the warehouse state exactly which
lots and how many packages are shipped, which is essential for
traceability, labeling and customer claims.

Usage
=====

Configure a multi-step operation type to propagate variable quantities.
When the done package count is entered on the source operation,
downstream reserved move lines keep that count instead of recalculating
it from the changed weight.
