To use this module:

1.  Set a product with 'Make to order' route.
2.  Set a supplier for this product to buy it.
3.  Make some sales to customer with this product and a purchase order
    will be created.
4.  Confirm de purchase order.
5.  Go to the incoming picking created.
6.  You can change the quantity received, so is different than outgoing
    demand.
7.  Click on button near de quantity_done field on picking operations
    and a wizard will be appear with the outgoing moves.
8.  Now you can change the initial demand consistent with the quantity
    received.
