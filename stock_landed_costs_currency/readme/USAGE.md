To use this module, you need to:

1. Go to *Inventory > Operations > Landed Costs* and choose the *Account
   Journal* and the corresponding *Currency*.
2. Add a cost line and set the *Cost* column with the amount in that currency.
3. The amount in *Cost in Company Currency* is automatically converted to the
   company's currency using the exchange rate on the landed cost date.
4. After clicking *Validate*, the products are valued with amounts in the
   company's currency.
