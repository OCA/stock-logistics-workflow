Go to Inventory > Reporting > Withdrawal Valuation.

A wizard dialog will appear where you can:

* **Customer**: select a customer to filter withdrawals. When selected, the
  customer's default pricelist is loaded automatically.
* **Pricelist**: change the pricelist used for price calculations. This does
  not modify any data — it only affects the report values.
* **From / To**: define the date range for the stock withdrawals.

All fields are optional. Click **Generate Report** to view the results.

The report shows outgoing stock move lines with:

* Original quantity, returned quantity, and net quantity.
* Unit price calculated from the selected pricelist.
* Total value (net quantity × unit price).

You can group by customer, product, date, or transfer using the search
view filters. The pivot view provides a summary by customer and product.
