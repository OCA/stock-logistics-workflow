.. contents::

Usage
=====

- This module adds a smart button on the stock picking form view to view
  related pickings.
- The smart button displays the number of related pickings (e.g.,
  inter-warehouse transfers).
- Clicking the button opens related pickings in tree view if multiple,
  or directly in form view if only one exists.
- Helps users quickly navigate and track all linked pickings in a
  transfer chain.
