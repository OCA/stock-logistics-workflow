Brings the return features of the sales order portal to the stock
operations portal:

- Delivered operations get a **Return** button, in the list of
  operations and on the page of the operation, giving the customer the
  return slip to put inside the parcel sent back.
- The page of a delivery lists its returns with their date and status:
  awaiting arrival, received or cancelled.
- The page of a return links back to the delivery it comes from.

Operations whose type is not published in the portal are shown by name,
without a link.

Use Cases / Context
===================

Odoo already gives customers a return slip and a list of their returns,
but only on the portal page of a sales order. Deliveries that are not
linked to a sales order, such as those created manually, imported, or
generated by another application, never appear on that page: their
customers cannot get a return slip, nor see whether their return has
arrived.

*Stock Picking Portal* shows those deliveries to the customer. This
module brings the return features of the sales order portal to it, so
every delivery published in the portal can be returned the same way.

Configuration
=============

Go to *Inventory > Configuration > Settings* and add both the delivery
operation type and its return operation type to *Portal Visible
Operations*, so customers can navigate between a delivery and its
returns.

Usage
=====

1. Log in to the portal as a customer and open *Stock Operations*.
2. On a delivered operation, click **Return** to get the return slip,
   then put it inside the parcel sent back.
3. Once the warehouse has created the return, the page of the delivery
   lists it under *Returns* as *Awaiting arrival*, then as *Received*
   when it has been validated. The page of the return links back to the
   delivery.
