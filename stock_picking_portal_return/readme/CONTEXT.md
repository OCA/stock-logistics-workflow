Odoo already gives customers a return slip and a list of their returns, but
only on the portal page of a sales order. Deliveries that are not linked to a
sales order, such as those created manually, imported, or generated by another
application, never appear on that page: their customers cannot get a return
slip, nor see whether their return has arrived.

*Stock Picking Portal* shows those deliveries to the customer. This module
brings the return features of the sales order portal to it, so every delivery
published in the portal can be returned the same way.
