1. Log in to the portal as a customer and open *Stock Operations*.
2. On a delivered operation, click **Return** to get the return slip, then put
   it inside the parcel sent back.
3. Once the warehouse has created the return, the page of the delivery lists it
   under *Returns* as *Awaiting arrival*, then as *Received* when it has been
   validated. The page of the return links back to the delivery.
