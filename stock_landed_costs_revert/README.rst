This module allows you to generate new landed costs from one already
generated with the value of the lines in negative, thus simulating a
reversal.

   :local:

Usage
=====

Create new landed costs
-----------------------

1. Go to *Inventory* > *Operations* > *Landed Costs*
2. Create a new landed costs
3. When the landed costs are validated, a *Revert* button appears, this
   button only appears in the Posted state.
4. Pressing this button generates a new landed cost in draft status.
5. To view the reverted landed costs, press the "Landed costs reverted"
   smart button.
