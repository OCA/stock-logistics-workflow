To use this module, you need to:

1. Go to Sales > Quotations.
1. Create new quotation to the desired customer.
1. Add storable product in order lines.
1. Activate **customer deposit** in quotation.
1. Check *route* in order line is customer deposit.
1. Add elaboration with route in order line.
1. Check *route* in order line is still customer deposit.
1. Deactivate **customer deposit** in quotation.
1. Check *route* in order line the route of elaboration.
