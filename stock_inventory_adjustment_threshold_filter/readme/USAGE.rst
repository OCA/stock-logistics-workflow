* Go to *Inventory > Operations > Inventory Adjustments (Threshold
  Filter)*.
  The *To Apply* filter is applied by default.
* Optionally narrow down the adjustment cost / quantity difference
  threshold sliders and the Positive/Negative/Zero Adjustment flags in
  the left panel to match your validation policy. Each threshold can be
  switched between *At Least* (keep everything above the threshold, to
  spot the adjustments that need attention) and *At Most* (keep
  everything below the threshold, to bulk-process the ones that don't).
* Select the quants to apply (standard Odoo behavior: the *Apply* /
  *Clear* / *Request a count* buttons only show up once at least one
  quant is selected). If the search matches more quants than are
  currently loaded on the page, use the *Select all N* link to extend
  the selection to every matching quant instead of just the visible
  ones.
* Click *Apply* and give the inventory adjustment a name/reference when
  prompted: the selected quants are applied.
