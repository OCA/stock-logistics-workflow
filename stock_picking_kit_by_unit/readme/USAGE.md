To receive, on the Stock Receipt:

1. On the picking form, click the "Kit Ops" button to open the
   Kit Operations list view. This shows the move lines for kit
   components sorted per box (kit unit), with the first line of
   each box displayed in bold.
2. Enter the serial/lot numbers for each component, processing
   one box at a time.
3. Click "Put in Pack" to manually pack selected lines, or use
   "Pack All Kits" to automatically group all kit lines per box
   and create a package for each.
4. When validating the picking, any unpacked kit lines are
   automatically packed. Each package is named after the first
   serial number in the box.
