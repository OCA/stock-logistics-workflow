To use this module, you need to:

1. Configure auto create lot on the operation type and product (see Configure).
2. Create a purchase order using a packing UoM different from the product UoM
   when needed (for example *Dozen* or a custom *Box*).
3. Confirm the purchase order and open the related incoming picking.
4. Validate the picking without filling the lot number (or with an existing
   lot).
5. Open the created/selected lot: **Packing UoM** and **Original Received Qty**
   are filled automatically.
6. Open Inventory / Stock: quant lists show **Packing Qty** and **Packing UoM**,
   and you can group by packing UoM.
