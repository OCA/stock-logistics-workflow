This module stores the original packing Unit of Measure and received quantity
on lots when goods are received, and shows the remaining quantity expressed in
that packing UoM on stock quants.

It depends on **Stock Picking Auto Create Lot** for automatic lot generation
on incoming pickings. After lots are created or selected, this module saves the
packing UoM and received quantity on the lot record.

Installation
============

To install this module, you need to:

1. Download the module from the OCA repository.
2. Add the module path to your Odoo addons path.
3. Update the Apps list.
4. Install **Stock Lot Packing UoM**.

Configuration
=============

To configure this module, you need to:

1. Install **Stock Picking Auto Create Lot** (dependency).
2. Go to *Inventory > Configuration > Operation Types*.
3. Enable **Auto Create Lot** on the incoming operation type.
4. Go to *Inventory > Products* and open a product tracked by lots/serials.
5. Enable **Auto Create Lot** on that product.

Usage
=====

To use this module, you need to:

1. Configure auto create lot on the operation type and product (see Configure).
2. Create a purchase order using a packing UoM different from the product UoM
   when needed (for example *Dozen* or a custom *Box*).
3. Confirm the purchase order and open the related incoming picking.
4. Validate the picking without filling the lot number (or with an existing
   lot).
5. Open the created/selected lot: **Packing UoM** and **Original Received Qty**
   are filled automatically.
6. Open Inventory / Stock: quant lists show **Packing Qty** and **Packing UoM**,
   and you can group by packing UoM.
