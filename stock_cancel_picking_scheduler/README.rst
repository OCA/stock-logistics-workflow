Use Cases / Context
===================

When using orderpoints to fill in stock locations from reserve locations
will generate a lot of movements even if the quantity is not available.

These waiting pickings should be regenerated at scheduler next run.

Configuration
=============

- Go to Inventory > Configuration > Warehouse > Operation Types
- For the selected operation type, check the box 'Cancel Waiting Picking
  With Scheduler'
