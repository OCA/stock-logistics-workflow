This module adds a technical user group "Location Validate Inventory" to allow the
validation of the inventory of a location.

In standard, only users in the "Inventory Manager" group can perform this and
only if there is a quant on the location as you need to apply a counted quantity.

This module provides an action on a location to validate that the current
inventory is right. This will reset any counted differences and update the
location last inventory date.
