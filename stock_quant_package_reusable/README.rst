This module extends the standard Odoo "Put in Pack" functionality to
allow the selection of existing reusable packages.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Go to **Inventory > Configuration > Operations Types**.
2. Select an Operation Type.
3. Enable the **"Use Reusable Pack"** checkbox.

Usage
=====

1. Open a Transfer that belongs to an Operation Type set as **Use
   Reusable Pack**.
2. Set quantities to be put in pack.
3. Click the **Put in Pack** button.
4. A pop-up wizard will appear titled **"Select Reusable Package"**.
5. Select a package from the dropdown. The list is filtered to show only
   reusable packs currently sitting in your warehouse.
6. Click **Confirm**.
7. The items are assigned to the selected package, and the standard Odoo
   packaging flow continues (updating move lines, creating package
   levels, etc.).
