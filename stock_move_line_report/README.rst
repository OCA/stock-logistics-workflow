Configuration
=============

To print the picking type labels from the operation type:

1. Go to to *Inventory > Configuration > Operation types*
2. Choose the desired operation type.
3. Choose the **Detailed operation label report**.
4. Enable **Show detailed operations**.

Usage
=====

To print the labels:

1. Go to a picking with detailed operations and which type has a report
   defined.
2. In the detailed operations with done quantities you'll be able to
   print the labels.
