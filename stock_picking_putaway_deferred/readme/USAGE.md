1. Confirm a picking whose operation type has **Defer Putaway to Operator** enabled.
2. The move lines are reserved but their destination remains the move's generic
   destination location (putaway not yet applied). A **"Putaway not applied"**
   badge is visible on the form.
3. When ready to process the transfer, click **Recompute Putaways**. The button
   is available even if the picking has been printed.
4. Destination locations are updated according to the current putaway rules.
5. Validate the picking normally. Validation is blocked with a clear error message
   if putaway has not been applied.
