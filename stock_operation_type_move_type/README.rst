Configure the default move_type (Shipping Policy) on Operation Types
(stock.picking.type). Instead of using a hardcoded default, each
operation type can have its own default shipping policy.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Operation Type Setup:

1. Go to *Warehouse > Configuration > Operation Types*
2. Select or create an operation type
3. Set the **Default Shipping Policy** field:

   -  *As soon as possible* - Deliver products as they become available
   -  *When all products are ready* - Deliver all products at once

Usage
=====

How It Works:

-  New pickings created with this operation type will automatically use
   the configured shipping policy
-  Users can still override the shipping policy manually on individual
   pickings
-  Existing pickings are not affected by operation type changes

Example

Set *Receipts* operation type to "As soon as possible" for faster
processing, and *Customer Deliveries* to "When all products are ready"
for complete shipments.
