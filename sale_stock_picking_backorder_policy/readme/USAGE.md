To set a customer's backorder policy:

1. Open the contact form and go to the *Sales & Purchase* tab.
2. Set a *Sale Backorder Policy* (Ask, Always or Never). It is shared with the
   contact's delivery addresses.

On a sale order, the *Backorder Policy* is set by default from the delivery
address and can be adjusted manually before confirmation.

When the order is confirmed, the policy is carried over to the deliveries it
generates, including multi-step routes. On validation of a partial delivery:

- **Ask**: the usual backorder prompt is shown.
- **Always**: a backorder is created automatically.
- **Never**: the remaining quantity is cancelled.
