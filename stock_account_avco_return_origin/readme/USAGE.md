Once the setting is enabled, validating a supplier return of an AVCO product
values the return at the original receipt price and realigns the product's
average cost accordingly. The valuation layer's description notes that the
original receipt price was used.

If a return would empty the product's stock on hand (so that pricing it at the
original receipt price would leave residual value with no stock to absorb it),
that return is valued at the standard average cost instead. This keeps the
valuation consistent without blocking the operation or requiring a manual
revaluation.
